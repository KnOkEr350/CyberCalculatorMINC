# Одиннадцать экранов ТЗ 4.4

Frontend использует единый registry `frontend/screens.js`, из которого shell строит нумерованное боковое меню, заголовок продукта и маршрутизацию. Рабочая область занимает высоту окна и прокручивается независимо от закреплённых topbar и sidebar.

| Экран | Реализация frontend |
|---|---|
| 1. Дашборд | KPI норматива 3%, план/факт/профицит, обязательные чипы ВО, распределение рисков и таблица всех видов |
| 2. Партнёры | Единый маршрут к реестру образовательных организаций либо ИТ-компаний в зависимости от контекста пользователя |
| 3. Преподаватели | Отдельный маршрут, только категория `teachers`, семестровые проверки, реестр и расчёт |
| 4. ООП / РПД | Отдельный маршрут `ood_rpd` с существующей матрицей документов и видов работ |
| 5. Стажировки | Отдельный маршрут `internship`, наставники, часы, формула и документы |
| 6. Практика | Отдельный маршрут `employment_practice` с полями и проверкой срочного трудового договора |
| 7. ТОП-ИТ / ИИ | Отдельный маршрут `top_it`, доступный только для аудитории ВО |
| 8. Школы | Один экран с тремя категориями: ИТ-кружки, повышение квалификации и образовательный контент |
| 9. Решение МЦ | Отдельный маршрут `minc_decision` для мероприятий с ручной подтверждённой стоимостью |
| 10. Отчётность | Конструктор среза, готовность комплекта и действующие XLSX/DOCX-выгрузки; будущие `.pkg` и формы АНО АЦ явно отключены до появления API |
| 11. Настройки | Контекст экземпляра, 3% база, безопасность профиля; для администратора также пользователи, ОКЗ, хранение и Audit Trail |

Экраны мероприятий используют общий проверенный workspace и backend-метаданные полей, но каждый route ограничивает допустимые категории и аудиторию. Это исключает смешение практики со стажировками и школьного трека с мероприятиями ВО/СПО.

Registry покрыт тестом порядка экранов, уникальности маршрутов и полного распределения категорий. Расширенные функции, для которых ещё нет backend-контракта (`.pkg`, Diff Engine, snapshots, CryptoEngine, шестилистовая форма АНО АЦ), не имитируют успешную операцию и отображаются отключёнными.
