# Версионированный API-контракт

Актуальный контракт HTTP API хранится в [`api/openapi/v1.json`](../api/openapi/v1.json) в формате OpenAPI 3.1. Версия файла относится к линии API v1; изменение несовместимого wire format требует нового версионированного файла.

Контракт фиксирует:

- все зарегистрированные HTTP-методы и пути `/api/*`;
- единый JSON-формат ошибок и ошибок полей;
- пагинацию через `offset` и заголовок `X-Next-Offset`;
- UUID, календарные даты и время RFC 3339;
- деньги как десятичную JSON-строку с двумя знаками после точки;
- multipart upload и потоковый download с метаданными файла.

## Проверка

Из каталога `backend`:

```bash
go run ./cmd/apicontract ../api/openapi/v1.json ./internal/modules
```

Проверка разбирает контракт, сверяет обязательные схемы и сравнивает операции OpenAPI со всеми маршрутами, зарегистрированными модулями backend. Новый или удалённый маршрут без синхронного изменения контракта блокирует CI.

Совместимость денежных входных данных сохранена: backend принимает прежнее JSON-число и новый строковый формат, но ответы сериализуются только строкой, чтобы исключить потерю точности.
