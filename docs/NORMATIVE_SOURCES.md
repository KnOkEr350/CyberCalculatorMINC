# Реестр нормативных источников

BASE-13 хранит каждую официальную редакцию как неизменяемую запись: код и
название акта, обозначение редакции, даты публикации и действия, HTTPS URL,
точный host источника, исходные байты, MIME, имя, размер и SHA-256. UPDATE и
DELETE реестра и протоколов запрещены триггерами БД.

Импорт доступен только администратору через
`POST /api/admin/normative-sources/import` (`multipart/form-data`). Клиент
передаёт `act_code`, `title`, `revision`, необязательный `published_on`,
обязательные `effective_on`, `source_url`, `sha256` и `file`. Сервер:

1. вычисляет SHA-256 по реально загруженным байтам;
2. принимает только HTTPS и точное совпадение host с allowlist БД;
3. проверяет сигнатуру/тип PDF, DOCX, XLSX, JSON, CSV или UTF-8 text;
4. блокирует ту же редакцию с иными метаданными или SHA-256;
5. блокирует две редакции одного акта с одной датой действия;
6. атомарно пишет редакцию, diff с предыдущей редакцией и audit event.

Начальный allowlist содержит официальные домены `publication.pravo.gov.ru`,
`pravo.gov.ru`, `digital.gov.ru` и `adm.digital.gov.ru`. Поддомены, похожие
домены и нестандартные порты не считаются доверенными.

`GET /api/admin/normative-sources/diff` строит воспроизводимый протокол для
двух зарегистрированных редакций. Для текстовых данных он включает
отсортированные добавленные/удалённые строки (до 200 с флагом усечения), для
бинарных — идентификаторы, редакции, размеры и SHA-256. Автоматически созданный
при импорте протокол сохраняется в `normative_revision_diffs`.

Реестр не подменяет юридическую сверку содержания: до использования файла как
golden template ответственный сотрудник сопоставляет его с карточкой акта на
официальном портале и регистрирует опубликованный checksum.
