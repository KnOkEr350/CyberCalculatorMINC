# Справочник ОКЗ

Реализация DATA-05 хранит версии Общероссийского классификатора занятий ОК 010-2014 (МСКЗ-08). Официальный статус и изменения классификатора публикует [Росстандарт](https://protect.gost.ru/classificators/details/0d7c57d3-084a-42e7-bdda-3c68bbc01731).

## Возможности

- импорт новой версии из CSV через интерфейс администратора;
- атомарное переключение активной версии с сохранением истории;
- проверка формата, уникальности и полной иерархии кодов;
- поиск по коду и наименованию с фильтром уровня и пагинацией;
- запись импорта в журнал аудита;
- защищённые API: поиск доступен авторизованным пользователям, обновление — только администратору.

## Формат CSV

Поддерживаются UTF-8, разделители `;` и `,`, русские или английские заголовки:

```csv
code;name
2;Специалисты высшего уровня квалификации
25;Специалисты по информационно-коммуникационным технологиям
251;Разработчики и аналитики программного обеспечения и приложений
2512;Разработчики программного обеспечения
```

Код содержит от одной до четырёх цифр. Для каждой строки второго–четвёртого уровня файл обязан содержать родительскую группировку: например, для `2512` нужны `251`, `25` и `2`. Повторяющиеся коды и неполная иерархия отклоняются до изменения базы данных.

CSV-шаблон доступен в разделе «Управление → Справочник ОКЗ» и по `GET /api/admin/okz/template`.

## API

- `GET /api/okz?q=&level=&limit=&offset=` — поиск по активной версии;
- `GET /api/admin/okz/versions` — история версий;
- `GET /api/admin/okz/template` — шаблон CSV;
- `POST /api/admin/okz/import` — multipart-импорт и активация версии.

Если проверка CSV или сохранение завершается ошибкой, предыдущая активная версия остаётся неизменной.
