# Матрица семестров преподавания

Реализация `TCH-02` применяет к записям Вида 1 строгую матрицу из ТЗ 4.4:

| Уровень программы | Внутреннее значение | Допустимые семестры |
|---|---|---:|
| Бакалавриат | `bachelor` | 1–8 |
| Магистратура | `master` | 9–12 |
| Специалитет | `specialist` | 1–13 |
| СПО | `spo` | 1–10 |

Поля `education_level` и `semester` обязательны для новых и изменяемых записей преподавания. Проверка выполняется на backend при ручном вводе и импорте XLSX; поэтому её нельзя обойти прямым API-запросом. Интерфейс показывает только нормализованные уровни и сразу ограничивает диапазон семестра.

Граничные значения всех четырёх диапазонов покрыты unit-тестами. Интеграционный тест API дополнительно проверяет отклонение девятого семестра для бакалавриата.

## Срезы дашборда по семестру и светофору

По заготовке МЦ «Светофор» (файл «МЦ_светофор_Шаблон.xlsx», в репозитории не хранится) семестр — реквизит записи, а не отдельный справочник: у преподавания он обязателен (таблица выше), у РПД добавлен необязательный `semester` (1–13). Дашборд принимает три необязательных параметра, которые сужают одну и ту же проекцию (все агрегаты и корзины риска сходятся между собой):

| Параметр | Значения | Смысл |
|---|---|---|
| `semester` | 1–13 | записи ровно этого семестра |
| `term` | `autumn`, `spring` | нечётные (осенние) или чётные (весенние) семестры |
| `light` | `green`, `yellow`, `red` | «можем подтвердить сейчас», «подтвердим, но есть вопросы», «низкая вероятность» |

Записи без семестра в семестровый срез не попадают. Некорректное значение отклоняется с кодом 400. Целевая сумма 3% и её выполнение от срезов не зависят: они считаются по всей организации.
