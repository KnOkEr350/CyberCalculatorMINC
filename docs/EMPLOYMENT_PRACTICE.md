# Официальное трудоустройство практиканта

Реализация `PRA-03` отделяет практику с трудоустройством (`employment_practice`) от обычной стажировки (`internship`). Формула расчёта остаётся общей, но для практики обязательны:

- тип договора — только срочный трудовой договор (`fixed_term`);
- номер срочного трудового договора;
- корректная календарная дата договора в формате `YYYY-MM-DD`.

Проверка выполняется на backend до расчёта и сохранения записи и используется ручным API-вводом, редактированием и XLSX-импортом. Frontend отображает отдельные поля договора и сразу блокирует выбор другого типа договора. Обычная стажировка не получает поля практики и остаётся отдельной категорией.
