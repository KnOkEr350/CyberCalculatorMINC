# ADR-04: Основная СУБД

- Статус: `ACCEPTED`
- Дата: 2026-09-21
- Владелец решения: технический руководитель
- Основание: [`DECISIONS.md`, раздел 1](../../DECISIONS.md)
- Блокирует: не блокирует

## Решение

Основной и обязательной СУБД текущей реализации является PostgreSQL 16.
SQLite/SQLCipher не входит в обязательную матрицу поддержки. Возврат к
двухбазовой поддержке потребует нового ADR и отдельной оценки миграций,
конкурентной записи, SQL-диалекта, резервного копирования и шифрования.

## Последствия

- Миграции и integration tests могут использовать возможности PostgreSQL.
- Offline appliance поставляет локальный PostgreSQL как часть runtime.
- Код не должен заявлять совместимость с SQLite без отдельного quality gate.

## Проверка

Поддерживаемая версия СУБД зафиксирована в документации, compose и CI; полный
набор миграций применяется на чистом PostgreSQL 16.
