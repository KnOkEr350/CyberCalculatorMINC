# ADR-11: Гранулярность обязательных Видов 1 и 3

- Статус: `ACCEPTED`
- Владелец решения: владелец продукта совместно с юристом
- Дата решения: 21 сентября 2026 года
- Основание: Приказ № 270, приложение № 1 и правило ТОП-ИТ/ТОП-ИИ
- Блокирует: —

## Контекст

ТЗ устанавливает обязательность Видов 1 и 3 для ВО, но не определяет, должна
ли она проверяться на уровне вуза, программы, специальности, соглашения или
всей ИТ-компании за отчётный год.

## Решение

Проверка выполняется для каждого соглашения с конкретной образовательной
организацией ВО в отчётном году:

- Вид 1 должен иметь хотя бы один подтверждённый объём преподавания;
- Вид 3 должен иметь хотя бы одно подтверждённое мероприятие разработки,
  актуализации или экспертизы ООП/РПД;
- проверка не повторяется для каждой программы или специальности;
- для СПО эти виды не помечаются обязательными;
- исключение ТОП-ИТ/ТОП-ИИ применяется по ADR-03.

Если с одной ОО существует несколько соглашений на один год, каждое соглашение
оценивается отдельно, поскольку приказ требует реализацию в рамках каждого
соглашения и отчётные приложения формируются по каждому соглашению.

Запись учитывается только при `readiness=ready`, `eligibility=eligible`,
допустимом `approval` и отсутствии активного юридического сомнения.
