# ADR-06: Политика обязательности 2FA

- Статус: `PROPOSED`
- Владелец решения: Security owner
- Backlog: Technical/Security
- Блокирует: SEC-01, SEC-07, SEC-08

## Контекст

ТЗ описывает вход с TOTP, а текущая система позволяет пользователю работать
без включённой 2FA. Нужно определить обязательность по ролям и переходный
период для существующих аккаунтов.

## Варианты

1. 2FA обязательна для всех ролей.
2. 2FA обязательна только для привилегированных ролей.
3. Политика настраивается организацией с безопасным обязательным минимумом.

## Критерий принятия

Зафиксированы охват ролей, grace period, recovery/reset, защита от replay,
действия при потере устройства и аудит административного сброса.
