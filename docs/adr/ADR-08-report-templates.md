# ADR-08: Эталонные шаблоны отчётности

- Статус: `PROPOSED`
- Владелец решения: владелец продукта совместно с юристом
- Backlog: Product/Legal
- Блокирует: REPORT-03–REPORT-09, REPORT-12

## Контекст

Генераторы XLSX/DOCX нельзя принимать только по текстовому описанию. Нужны
утверждённые формы приложений № 1–5 и отчёта АНО АЦ с точными листами,
колонками, объединениями, форматами и обязательными реквизитами.

## Варианты

1. Подписанные заказчиком файлы принимаются как единственный golden source.
2. Формы восстанавливаются из нормативных документов и отдельно утверждаются.

## Критерий принятия

В репозитории зарегистрированы версии эталонов с SHA-256, источником, датой
действия и правилами структурного сравнения без персональных данных.
