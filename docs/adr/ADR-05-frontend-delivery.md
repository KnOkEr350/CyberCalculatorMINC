# ADR-05: Способ доставки frontend

- Статус: `PROPOSED`
- Владелец решения: технический руководитель
- Backlog: Technical
- Блокирует: OPS-01, OPS-04, OPS-11

## Контекст

Сейчас frontend поставляется отдельным nginx-контейнером. ТЗ 4.4 допускает
единый appliance, для которого возможна раздача SPA из Go через `go:embed`.

## Варианты

1. Сохранить отдельный frontend-контейнер.
2. Встроить собранный frontend в Go-бинарник.
3. Поддерживать оба режима из одного воспроизводимого артефакта.

## Критерий принятия

Выбрана целевая схема, описаны cache headers, CSP, offline bundle, обновление и
rollback; smoke test проходит без доступа к сети.
