# ADR-24: Доплата по договорам ГПХ не реализуется

- Статус: `ACCEPTED`
- Владелец решения: владелец продукта
- Основание: решение встречи по дашборду («светофору»)
- Блокирует: —

## Контекст

Договоры гражданско-правового характера (ГПХ) допускаются как основание
привлечения преподавателя и остаются документом комплекта (TCH-05). Вопрос
возник о том, нужно ли автоматически считать и показывать доплату по ГПХ сверх
стоимости мероприятия по Методике.

## Решение

Доплата по ГПХ в системе не считается, не хранится и не показывается. Сумма
мероприятия равна значению по Методике приказа № 270 (DATA-07). Договор ГПХ
по-прежнему проверяется как документ комплекта и влияет на готовность, но не
на сумму.

## Последствия

Расчётные модули, экспорт и дашборд не содержат поля или строки доплаты по ГПХ;
запросы на неё отклоняются как вне объёма без нового ADR. Если решение будет
пересмотрено, оформляется новый ADR, а этот получает статус `SUPERSEDED`.
