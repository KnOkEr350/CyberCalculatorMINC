# ADR-18: Соотношение readiness, eligibility и approval

- Статус: `PROPOSED`
- Владелец решения: владелец продукта совместно с юристом
- Backlog: Product/Legal
- Блокирует: ActivityProjection, RISK-01, REPORT-01, DASH-01

## Контекст

Комплектность данных, регуляторная допустимость и формальное согласование —
разные состояния. Их смешение приводит к включению незачётных сумм в отчёт
или блокирует работу с ещё не согласованными черновиками.

## Предлагаемая модель для обсуждения

- `readiness`: достаточно ли данных и документов для проверки;
- `eligibility`: допускается ли расход правилами;
- `approval`: прошёл ли объект установленный workflow согласования.

## Критерий принятия

Утверждены независимые state machines, порядок вычисления counted amount и
матрица всех значимых комбинаций трёх состояний.
