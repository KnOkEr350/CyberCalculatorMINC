# ADR-03: Исключение ТОП-ИТ по пункту 22

- Статус: `PROPOSED`
- Владелец решения: владелец продукта совместно с юристом
- Backlog: Product/Legal
- Блокирует: TOP-08, RISK-05, DASH-03, REPORT-01

## Контекст

ТЗ допускает не реализовывать другие виды в одной ОО при ТОП-ИТ/ТОП-ИИ, если
обязательные Виды 1 и 3 одновременно реализуются как минимум в одной иной ОО.
Нужна однозначная область проверки по году, соглашению и организации.

## Варианты

1. Проверка на уровне ИТ-компании и отчётного года.
2. Проверка отдельно для каждой программы/соглашения.
3. Проверка по каждой специальности или направлению подготовки.

## Критерий принятия

Утверждена булева формула с положительными и отрицательными примерами, включая
несколько ОО, несколько программ и частично подтверждённые Виды 1 и 3.
