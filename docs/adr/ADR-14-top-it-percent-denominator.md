# ADR-14: Знаменатель процентов ТОП-ИТ/ТОП-ИИ

- Статус: `PROPOSED`
- Владелец решения: владелец продукта совместно с юристом
- Backlog: Product/Legal
- Блокирует: TOP-03, TOP-08, UI-07, REPORT-09

## Контекст

ТЗ упоминает плановую сумму софинансирования X, сумму гранта и пороги 30/70%.
Без фиксированного знаменателя progress gauge и регуляторный вывод могут
противоречить друг другу.

## Варианты

1. Фактически списанные средства / план X.
2. Фактически списанные средства / сумма гранта.
3. Раздельно показывать выполнение X и норматив 30/70% от гранта.

## Критерий принятия

Утверждены знаменатели для каждого показателя, источники сумм, правила для
изменённого договора и контрольные примеры для порогов 30% и 70%.
