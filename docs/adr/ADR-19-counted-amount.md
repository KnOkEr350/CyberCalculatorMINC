# ADR-19: Источник зачётной суммы по видам

- Статус: `ACCEPTED`
- Владелец решения: владелец продукта совместно с юристом
- Дата решения: 21 сентября 2026 года
- Основание: Приказ № 270 и приложение № 6
- Блокирует: —

## Контекст

Для разных видов доступны нормативная стоимость, план, заявленный факт,
подтверждённый факт и фактически списанные средства. Официальный отчёт должен
использовать единый явно объяснимый источник зачётной суммы для каждого вида.

## Решение

Для каждой записи хранится `valuation_method = average | actual`, исходные
показатели и объяснение расчёта.

- `average`: `counted_amount` рассчитывается строго по версии Методики и
  тарифов, действующей для отчётного периода.
- `actual`: `counted_amount` равен документально подтверждённым фактическим
  затратам. Использование фактических значений требует приложить к итоговому
  отчёту документ аудитора о достоверности объёма финансового обеспечения.
- Вид 4: источником служит объём расходов из принятого отчёта о
  софинансировании/отчёта ОО и письмо о согласовании АНО АЦ.
- Вид 5: единица и стоимость определяются Решением Минцифры; используется
  фактическая стоимость.
- Виды 1–3 и 6–8 при `average` используют отдельные формулы Методики, а не
  общую формулу `min(fact, norm)`.

План и перечисленная сумма не являются зачётной суммой сами по себе. Отрицательные
корректировки оформляются отдельными записями, ссылающимися на исходную; история
не перезаписывается. Расчёты ведутся в точной decimal-арифметике, округление —
только на нормативной границе/при выводе согласно форме.

## Контроль отчёта

Если хотя бы одна включённая запись использует `actual`, readiness итогового
отчёта требует аудиторский документ. Каждая сумма содержит explanation с
версией тарифа, формулой либо ссылками на документы фактических затрат.
