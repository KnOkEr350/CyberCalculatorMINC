# ADR-19: Источник зачётной суммы по видам

- Статус: `PROPOSED`
- Владелец решения: владелец продукта совместно с юристом
- Backlog: Product/Legal
- Блокирует: все доменные расчёты, DASH-01, REPORT-01

## Контекст

Для разных видов доступны нормативная стоимость, план, заявленный факт,
подтверждённый факт и фактически списанные средства. Официальный отчёт должен
использовать единый явно объяснимый источник зачётной суммы для каждого вида.

## Варианты

1. Подтверждённый факт, ограниченный нормативной стоимостью.
2. Минимум подтверждённого факта, оплаты и нормативного лимита.
3. Отдельная формула по каждому виду и подвиду.

## Критерий принятия

Для Видов 1–8 утверждена таблица входных сумм, формула `counted_amount`,
правила округления, отрицательных корректировок и текст explanation.
