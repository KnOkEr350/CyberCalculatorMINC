# Справочник образовательных организаций и соглашения

## Почему старые 1 257 записей нельзя выбирать

Начальный набор получен из мониторинга ВО 2025. Он сохранён как исторический
источник, но не содержит ИНН, ОГРН и текущий статус лицензии. Поэтому приложение
не выдаёт его за полный реестр и не разрешает создавать из него новых партнёров.
Существующие партнёры и их расчёты не удаляются.

## Первичная загрузка официального справочника

Администратор открывает «Учебные заведения» → «Обновить из выгрузки реестра»,
скачивает шаблон и переносит в него официальную выгрузку. Для каждой строки
обязательны:

- полное наименование, тип и субъект РФ;
- ИНН и ОГРН/ОГРНИП (сервер проверяет контрольные суммы);
- номер и текущий статус лицензии, статус юридического лица;
- устойчивый идентификатор записи, дата актуальности и HTTPS-ссылка на карточку
  Рособрнадзора либо другого официального домена `*.gov.ru`.

Импорт сначала выполняется в режиме проверки. Если ошибочна хотя бы одна строка,
в базу не записывается ничего. Проверенными и доступными для выбора считаются
только действующие записи, обновлённые не более 35 дней назад.

## Автоматическое обновление

Если официальный XLSX в формате шаблона доступен по постоянному HTTPS-адресу,
задайте в `.env`:

```dotenv
DIRECTORY_SYNC_URL=https://официальный-домен.gov.ru/path/registry.xlsx
DIRECTORY_SYNC_INTERVAL_HOURS=24
```

Backend проверяет выгрузку сразу после запуска и затем по расписанию. При двух
репликах обновление выполняет только одна из них. Ошибка не приводит к частичной
замене справочника; результат последнего запуска виден на странице справочника.

## Соглашения

Новый партнёр создаётся только из проверенной записи и одновременно с первым
соглашением. После этого кнопка «Соглашения» позволяет завести дополнительные
соглашения, соглашение с РОИВ, общий договор для нескольких учебных заведений,
ответственных лиц обеих сторон и реквизиты подписания.

Каждая новая или изменённая запись плана/факта и каждая строка Excel-импорта
обязательно ссылаются на действующее соглашение, которое охватывает выбранное
учебное заведение и отчётный год. Старые соглашения мигрируются со статусом
«Требует проверки»: их нужно открыть, уточнить реквизиты и сохранить с реальным
статусом до внесения новых расчётов.

## РОИВ и школьные мероприятия

Региональный орган управления образованием ведётся отдельной сущностью в
справочнике РОИВ. Для него обязательны полное наименование, субъект РФ, ИНН,
ОГРН, статус и ссылка на официальный HTTPS-источник.

Соглашение типа «С РОИВ» обязательно ссылается на действующий РОИВ и может
охватывать только школы. Обычное соглашение с образовательной организацией не
может использоваться для новой школьной активности. Таким образом, связь
проверяется сервером по цепочке:

`РОИВ → соглашение → одна или несколько школ → записи плана/факта`.

Если РОИВ переведён в статус «Не действует», существующая история сохраняется,
но новые школьные записи по его соглашениям блокируются. Название РОИВ также
выводится в Excel- и Word-отчётах.
